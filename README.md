# Dandy Aryo Putra · Personal Edition

An interactive phone portfolio about the journey from aircraft maintenance to business operations and management.

**Live:** https://dandyaryo.github.io/dandy-au-portfolio/

## Experience

- Portrait lock screen with swipe unlock, WIB clock, titanium phone frame, status indicators, home pages, dock, app switcher, notifications and app search.
- Control Center and Settings for in-site brightness, sound, focus, dark mode, wallpaper and reduced motion.
- Indonesian, English, Japanese and Simplified Chinese throughout the core UI, career narrative and work conversations.
- 26 apps including 7 branching work conversations, 26 career milestones, certificate albums, notes, calendar, calculator, stopwatch/timer, opt-in camera, local coding playground and contact card.
- CERDAS, WMS, MITRA, HRIS and SRMS scrollable portfolio demonstrations. All operational records are illustrative. No company backend is connected.
- ChatGPT, Claude and Gemini portfolio companions use curated responses and link to the official services. They do not impersonate a live model or use paid API access.
- Instagram @uandandy uses the publicly visible profile photo and eight posts captured on 12 November 2026. LinkedIn displays a public-profile summary. Both open the original profile. Social metrics are dated snapshots, not live feeds.
- Hire Me presents monthly salary expectations of USD 2,000 and USD 3,500, with role scope and AI-assisted working approach. Selecting a position prepares a WhatsApp link; the visitor sends the message themselves.

## Content and privacy

Work conversations are labeled reconstructions, not copied private chats. Career chronology follows the owner's supplied history. The 80+ certificate figure is owner-provided; individual certificates are only displayed after supplied files are added. Browser settings, reading progress, notes and playground edits stay in the current browser. Camera captures stay in memory and disappear on reload.

Network/battery indicators, weather and flashlight are portfolio simulations. Brightness affects this web experience only. The phone interface is an independent portfolio, not an Apple product.

## Maintain

Buildless HTML, CSS and JavaScript. GitHub Pages serves the repository root on `main`.

- `index.html`, `style.css`: shell, responsive presentation and motion.
- `ui.js`: four-language UI strings, app definitions and SVG icon set.
- `script.js`: navigation, gestures, local preferences and app behavior.
- `content.js`: localized career and conversation content.
- `systems.js`: isolated read-only system previews with synthetic data.
- `certificates.js`: gallery manifest for future certificate images/PDFs.
- `assets/`: portrait, generated career-themed background and approved public Instagram images.

To add a certificate, upload its public image or PDF into `assets/`, then add its relative file path, title and category to `certificates.js`. Use a thumbnail image for PDFs. Never upload private identifiers or internal company records. No certificate credentials are fabricated by the gallery.

For a local static preview, serve this directory with a static web server. No package installation, backend, API keys or build step is needed.
